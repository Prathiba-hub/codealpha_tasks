# TASK 1 — Simple E-commerce Store

## Project Description
A basic e-commerce web application built using Django where users can browse products, add items to cart, and place orders.

## Features
- User Registration & Login
- Product Listings
- Product Details Page
- Shopping Cart
- Order Processing
- Database Storage

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

# How to Run the Projects

## Step 1 — Clone Repository

```bash
git clone https://github.com/yourusername/codealpha_tasks.git
```

---

## Step 2 — Open Project Folder

```bash
cd codealpha_tasks
```

---

## Step 3 — Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

---

## Step 4 — Run Django Server

```bash
python manage.py runserver
```

---

Open browser:
