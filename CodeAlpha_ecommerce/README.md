# 🛒 Django E-commerce Store

A simple full-stack E-commerce Website built using Django.  
This project includes product listing, user authentication, shopping cart functionality, and order processing system.

---

## 🚀 Features

- User Registration & Login
- Product Listings with Images
- Shopping Cart System
- Order Processing
- Admin Dashboard
- Responsive UI Design
- SQLite Database Integration

---

## 🛠 Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- VS Code

## ▶️ How to Run the Project

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/django-ecommerce-store.git
```

### 2️⃣ Open Project Folder

```bash
cd django-ecommerce-store
```

### 3️⃣ Install Django

```bash
pip install django
```

### 4️⃣ Run Server

```bash
python manage.py runserver
```
